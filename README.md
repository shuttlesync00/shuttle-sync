# Shuttle Sync

Shuttle Sync is a badminton ecosystem MVP focused on architecture, auth, protected routes, and scalable feature-first organization.

## Architecture highlights

- Next.js 16 App Router with TypeScript
- Feature-first folder structure under src
- Supabase auth and Prisma data layer scaffolding
- Protected app layout and route groups for auth/app sections
- Reusable services, providers, types, and layout components
